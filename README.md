## Workflow

For every LeetCode problem:

1. Solve the problem on LeetCode.
2. Create the `.cpp` file in the appropriate topic folder.
3. Add the solution along with the approach and time/space complexity.
4. Check the repository status:

   ```bash
   git status
   ```
5. Stage the changes:

   ```bash
   git add .
   ```
6. Commit the solution:

   ```bash
   git commit -m "Solve LeetCode XXXX - Problem Name"
   ```
7. Push the commit to GitHub:

   ```bash
   git push
   ```

Each solved problem is maintained as a separate Git commit.
